# Dental Clinic Management System

Full-stack app for managing appointments, patients, and billing.

## Stack
- **Frontend:** React, Tailwind, Axios
- **Backend:** Node, Express, MongoDB

## Structure
- `/client` — React frontend
- `/server` — Express API
